# mili:on 기능 정리

> **예비군의 백만 가지 이야기, 하나도 꺼지지 않도록.**
> 예비군 훈련장 만족도 지도 → 훈련 설문 → 개선 제안 → 담당자 처리 → 보안 마스킹을 거친 AI 대책 초안 → 결과 공개까지 한 흐름으로 잇는 웹 서비스입니다.
> 2026 예비전력분야 혁신 아이디어 공모전 출품작. 화면의 데이터는 모두 가상입니다. 훈련장 이름은 가명(A~X훈련장)이고, 위치는 시군구 중심점입니다.

---

## 1. 사용자와 권한

| 역할 | 할 수 있는 일 |
| --- | --- |
| **비로그인** | 지도, 훈련장 정보, 제안 목록과 처리 상태, 개선 동향, 가이드를 열람 |
| **예비군** | 위의 모든 것 + 훈련 설문, 개선 제안 작성, 공감, 신고, 가이드 현장 팁 작성, Q&A 질문, 내 활동 |
| **훈련장 담당자** | 자기 훈련장의 제안 처리(상태 변경·공식 답변), 공식 안내 작성, Q&A 답변, AI 대책 초안, 대시보드, 처리 큐, 제안 분석(자기 훈련장만) |
| **정책 담당자** | 모든 훈련장에 대해 담당자 기능 + 전체·훈련장별 제안 분석, 훈련장별 만족도 표, 마스킹 감사 로그 |

### 로그인 방식
- **오프라인 시연:** 로그인 화면이나 상단의 "역할 전환"에서 시연 계정(예비군 / A훈련장 담당자 / 정책 담당자)을 골라 바로 시작합니다.
- **서버 + Supabase:** 이메일로 로그인하거나 가입합니다(별명·연령대 입력). 서버가 Supabase 토큰을 확인한 뒤 서명된 httpOnly 쿠키를 발급합니다. 가입하면 예비군 권한이고, 담당자 권한은 관리자가 부여합니다.
- **서버, Supabase 미설정:** 아이디와 비밀번호로 시드 계정에 로그인합니다(`demo`, `manager_ra01`, `policy` 빠른 선택 버튼 제공). 비밀번호는 배포 환경변수 `SEED_PASSWORD`입니다.

## 2. 예비군 화면

### 홈 `/`
- **첫 화면:** `mili` 옆의 스위치가 빨간 **off**에서 녹색 **on**으로 켜지는 연출과 함께 문구 "예비군의 백만 가지 이야기, 하나도 꺼지지 않도록."이 나옵니다. 스위치를 누르면 다시 켜지고, 움직임 줄이기 설정이면 처음부터 켜져 있습니다.
- **바로가기:** 훈련 설문 참여하기, 만족도 지도 보기
- **지표:** 이번 달 제안, 개선 완료, 평균 처리 기간
- **예비군의 목소리로 바뀐 것들:** 개선 사례 카드(Before / After). 국민권익위원회 권고 사례도 함께 보여 줍니다. PC는 좌우 화살표로, 모바일은 밀어서 넘깁니다.

### 만족도 지도 `/map`
- 전국 지도 위에 훈련장 핀과 점수를 표시합니다. 로컬 TopoJSON과 d3를 써서 외부 지도 API가 필요 없습니다.
- **지표 선택:** 종합 / 일정 고지 / 교통 / 식사 / 숙소·시설 / 운영·기타
- **필터:** 훈련 유형, 시도
- **추세:** 최근 3개월 상승·하락을 표시합니다.
- **평가 부족:** 평가가 5건 미만이면 점수 대신 "평가 부족"으로 표시합니다.
- **핀 묶음:** 핀이 겹치면 "경기 2곳 · 평균 3.4"처럼 묶고, 누르면 확대합니다.
- **지도 / 목록 보기**를 전환할 수 있습니다.

### 훈련장 상세 `/ranges/[id]`
- **만족도 탭:** 5개 지표 방사형 차트, 지표별 막대, 월별 추이, 평가 목록
- **개선 제안 탭:** 이 훈련장의 제안과 처리 상태
- **가이드 탭:** 공식 안내와 현장 팁, 준비물 체크리스트(체크한 내용은 내 브라우저에 저장)
- **Q&A 탭:** 질문하기, 자동 1차 답변, 담당자 답변

### 훈련 설문 `/survey`, `/ranges/[id]/review`
- **문항:** 훈련 일정 고지 · 교통 · 숙식 · 기타 영역의 15문항을 **불만족 ↔ 만족 5단계**로 답합니다. 16유형 성격 검사처럼 원 크기로 강도를 보여 줍니다.
- **진행:** 답하면 다음 문항으로 자동 스크롤되고, 위쪽에 진행률 막대가 따라옵니다.
- **훈련 정보:** 이수 기록에서 고르거나, 기록이 없으면 직접 입력합니다(훈련장 · 훈련 유형 · 날짜).
- **"다른 예비군에게 전하고 싶은 말":** 300자까지이고, 실시간 보안 경고가 붙습니다.
- **자격:** 이수 후 30일 이내, 같은 날 같은 훈련장은 1회만 참여할 수 있습니다.
- **점수 반영:** 응답이 5개 지표 점수로 바뀌어 지도와 훈련장 점수에 반영됩니다.

### 개선 제안
- **목록 `/proposals`:** 모든 제안과 처리 상태를 공개합니다. 훈련장, 분야, 처리 상태로 거르고 공감순·최신순으로 정렬할 수 있습니다.
- **작성 `/ranges/[id]/propose`:**
  - 분야 → 세부 주제 → 내용 순서로 씁니다.
  - **실시간 보안 경고**가 붙습니다. 가려질 부분은 노란 밑줄, 등록할 수 없는 내용은 빨간 밑줄로 표시합니다.
  - 비슷한 제안이 이미 있으면 보여 주고, **"공감하고 끝내기"**로 중복 제안을 줄입니다.
- **상세 `/proposal?id=`:**
  - 처리 단계를 표시합니다: 접수 → 검토 중 → 조치 계획 수립 → 개선 완료 / 장기 검토
  - 처리 이력과 담당자의 공식 답변을 보여 줍니다.
  - 공감과 신고를 할 수 있습니다. 신고가 3건 쌓이면 자동으로 숨겨집니다.

### 개선 동향 `/trends`, `/issue?id=`
- **분야별 제안·공감 순위:** 제안 수와 공감 수를 두 열로 나눠, 한 축에 겹치지 않게 보여 줍니다.
- **월별 추이:** 상위 4개 분야를 보여 주고, 나머지는 회색으로 합칩니다.
- **급증 알림:** 최근 4주 제안 수가 이전 12주 평균보다 크게 늘어난 분야를 알려 줍니다.
- **개선 이슈:** 비슷한 제안을 하나로 묶은 목록입니다.
  - **우선순위 점수:** log2(1 + 제안 + 공감) × 불만 강도 × 안전 관련 1.5 × 최근성. 계산 근거를 함께 공개합니다.
- **이슈 상세:**
  - 관련 제안, 훈련장별 분포, 처리 상태 분포를 보여 줍니다.
  - 담당자는 **AI 대책 초안**을 받을 수 있습니다(아래 4장).

### 훈련장 가이드 `/guide`
- **훈련장 선택:** 최근 본 훈련장을 기억합니다.
- **글 종류:** 담당자가 쓰는 **공식 안내**와 예비군이 쓰는 **현장 팁**이 있습니다.
- **분류:** 준비물, 교통편, 식사, 입소 절차
- **"도움이 됐어요"** 버튼이 있습니다.
- **일정 경고:** 현장 팁에 "10월 15일 08시"처럼 훈련 일정을 쓰면 경고합니다.
- **Q&A 자동 1차 답변:**
  - 그 훈련장 가이드에서 근거를 찾아 답하고, 근거로 쓴 글을 표시합니다.
  - 근거가 없으면 "담당자 답변을 기다리는 중"으로 남습니다.
  - **AI를 호출하지 않습니다.**

### 내 활동 `/my`
- 공감한 제안, 내가 쓴 제안, 이수 기록과 설문 참여 여부를 확인합니다.

### 보안 마스킹 체험 `/masking-demo`
- 아무 문장이나 넣으면 어떻게 가려지고 차단되는지 실시간으로 보여 줍니다. 인터넷 없이 동작합니다.

## 3. 관리 화면 (담당자)

### 대시보드 `/admin`
- **KPI:** 미처리 제안, 7일 이상 미처리(빨강), 이번 달 완료, 평균 처리 기간
- **급증 알림과 우선순위 상위 이슈**를 보여 줍니다.
- **훈련장별 만족도 표(정책 담당자):** 종합 점수, 3개월 변화, 평가 수, 처리 중 제안. 순위 번호 없이 이름순입니다.
- **시연 데이터 초기화 버튼:** 오프라인 시연 모드에서만 나옵니다.

### 처리 큐 `/admin/queue`
- 오래된 순으로 처리할 제안을 보여 줍니다.
- 상태 필터로 볼 범위를 고릅니다.
- 행을 고르면 상세, 상태 변경, 공식 답변을 할 수 있습니다.
- **같은 이슈의 제안을 한 번에 일괄 처리**할 수 있습니다.
- 7일 이상 미처리 제안은 빨간색으로 표시합니다.

### 제안 분석 `/admin/analysis`
- **범위:**
  - 훈련장 담당자는 **자기 훈련장만** 봅니다. 다른 훈련장을 요청해도 서버가 막습니다.
  - 정책 담당자는 **전체 또는 훈련장을 골라서** 봅니다.
- **기간:** 최근 30일 / 3개월 / 6개월 / 1년
- **지표:** 접수된 제안(이전 같은 기간 대비), 공감 합계, 조치율, 평균 처리 기간, 7일 이상 미처리
- **분야별 제안:**
  - 분야마다 고정 색 막대와 건수·비중을 보여 줍니다.
  - 처리 상태 구성 막대로 접수→검토→계획→완료 중 어디에 몰려 있는지 보여 줍니다.
  - 이전 기간보다 늘었는지 줄었는지 ▲▼로 표시합니다.
- **분야별 월별 추이(최근 6개월)**와 **많이 나온 세부 주제(상위 8개)**를 보여 줍니다.
- **훈련장별 분야 분포(정책 담당자, 전체 범위일 때):** 훈련장 × 분야 표입니다. 색이 진할수록 제안이 많고, 행을 누르면 그 훈련장 분석으로 바뀝니다.
- AI를 쓰지 않는 집계 화면입니다.

### 마스킹 감사 로그 `/admin/audit` (정책 담당자)
- AI 호출과 자동 답변마다 다음을 기록합니다.
  - 외부로 나간 텍스트(가려진 상태)
  - 종류별 가린 개수
  - 차단 여부와 사유
  - 사용한 공급자
- 차단된 건만 따로 볼 수 있습니다.

## 4. AI 대책 초안

- **위치:** 이슈 상세 → **"AI 대책 초안 보기"** (담당자 전용)
- **흐름:**
  1. 대표 제안 20건을 고릅니다(공감 많은 순).
  2. 고른 제안을 **다시 마스킹**합니다. 같은 대상은 같은 번호(`[부대_1]`)로 가립니다.
  3. 차단 내용이 있는 제안은 아예 빼고 보냅니다.
  4. AI(Gemini 등)가 초안을 씁니다: 문제 요약, 즉시 조치, 단기, 중장기(예산 필요 표시), 참고 사례, 확인 필요 사항, 신뢰도.
  5. 번호 토큰을 원래 말로 되돌립니다. 개인정보는 되돌리지 않습니다.
- **투명성:** 초안 아래에서 **AI에게 실제로 보낸 텍스트**를 그대로 볼 수 있습니다.
- **결정:** 담당자가 **채택 / 수정 후 채택 / 반려**합니다. 채택하면 관련 제안의 상태(기본값 "조치 계획 수립")를 한 번에 바꾸고 공식 답변을 등록할 수 있습니다. 훈련장 담당자는 자기 훈련장 제안만 바뀝니다.
- **제한:** 사용자당 1분에 5회까지 호출할 수 있습니다.
- **키가 없거나 오프라인일 때:** 미리 만들어 둔 초안(상위 이슈 10개)을 보여 주고, 화면에 그 사실을 표시합니다.
- **공급자:** `LLM_PROVIDER=gemini | claude | openai`, `LLM_API_KEY`, 선택 항목 `LLM_MODEL`. Gemini 기본값은 `gemini-2.5-flash`입니다.

> 상용 AI를 호출하는 곳은 **AI 대책 초안 한 곳뿐**입니다. Q&A 자동 답변, 제안 분석, 지도, 동향 등 나머지는 모두 AI 없이 계산합니다.

## 5. 보안 마스킹

같은 엔진(`lib/masking`)이 브라우저와 서버에서 똑같이 동작합니다.

### 차단: 저장과 전송 자체를 막음
- 좌표(군사 좌표, 위경도, 도·분·초, "북위")
- 암구호, 출입 비밀번호
- 작전계획, 작전 명령
- 비밀 등급(군사기밀, 대외비 등)
- 주요 시설 위치, 경계 취약점
- 병력·장비 배치, 근무 교대 시간

### 마스킹: 가려서 저장
| 종류 | 예 | 저장 모양 |
| --- | --- | --- |
| 부대·단대호 (육·해·공군, 해병대) | 제3보병사단, 52사단 213연대, ○○부대 / 제11전투비행단, 11전비, 공군작전사령부, 오산기지 / 제1함대 사령부, 해역방어사령부, 진해기지 / 해병 2사단 | `[부대]` |
| 사람(이름 + 계급·직책) | 김철수 상병, 박 중대장님 | `[인물]` |
| 상세 위치 | ○○리 123-4번지 | `[위치]` |
| 무기·장비 / 작전 용어 / 군사 시설 | K2, 박격포, 항공기 제식명(KF-21, F-15K, C-130), 함정명·선체번호(세종대왕함, DDG-991), 유도무기(천궁, 해성) / 매복, 비상소집, 출격, 해상초계 / 탄약고, 지휘소, 격납고, 방공포대 (사전 97개 + 제식명·선체번호 규칙) | `[장비]` `[작전용어]` `[시설]` |
| 개인정보 | 전화번호, 주민번호, 군번, 차량번호, 이메일 | `[전화번호]` 등 (복원 불가) |

### 적용 시점
1. **작성 중:** 실시간 밑줄 경고를 보여 줍니다(노랑: 가려짐, 빨강: 등록 불가).
2. **저장할 때:** 서버가 다시 검사합니다. 가린 글만 DB에 저장하고 **원문은 남기지 않습니다.**
3. **AI로 보낼 때:** 번호 붙은 토큰으로 다시 가리는 2차 안전망입니다.

### 오탐 방지와 검증
- "우리 부대", "정말 친절한 교관", "지원사업"의 "원사" 같은 일상 표현은 제외합니다.
- 전각 문자와 특수 하이픈은 정규화해서 우회를 막습니다.
- "공군기지", "해군 출신"처럼 군 이름만 있는 일반 표현과 "기지개", "전단지"는 가리지 않습니다.
- `npm run masking:eval`로 109문장 테스트와 시드 45건을 평가합니다(모두 100% 탐지, 잘못된 차단 0건).

## 6. 실행 모드와 배포

| | 오프라인 시연 모드 | 서버 모드 |
| --- | --- | --- |
| 설정 | `NEXT_PUBLIC_APP_MODE=demo` | `NEXT_PUBLIC_APP_MODE=server` |
| 결과물 | 정적 웹사이트(`out/`), **인터넷 없이 동작** | Next.js 서버 + PostgreSQL |
| 데이터 | 시드 JSON → 브라우저 메모리, 변경분은 브라우저 저장소 | Prisma, 서버 시작 시 마이그레이션과 시드 자동 실행 |
| AI | 미리 만든 초안 | 상용 AI 실호출(키가 없으면 미리 만든 초안) |
| 로그인 | 시연 계정 | Supabase 또는 시드 계정 |

- **오프라인 시연:** `npm run build:demo` → `npm run serve:demo`로 띄우고 `http://localhost:4173`을 엽니다. 같은 Wi-Fi의 다른 기기에서도 접속할 수 있습니다. 빌드할 때 외부 주소가 섞이면 실패하도록 검사합니다.
- **Railway:** GitHub 저장소 연결 + PostgreSQL을 추가하고 다음 변수를 넣습니다.
  - 필수: `DATABASE_URL`, `DIRECT_URL`, `NEXT_PUBLIC_APP_MODE=server`, `SESSION_SECRET`(16자 이상), `SEED_PASSWORD`
  - 선택: `LLM_*`, `NEXT_PUBLIC_SUPABASE_*`
  - `npm run start`가 마이그레이션 → 시드(데이터가 있으면 건너뛰고 시드 계정 비밀번호만 갱신) → 서버 순서로 실행합니다.
  - 헬스체크 주소는 `/api/health`입니다.
